RF Remote Enhanced 2.5.7 changes the default toggle-only light colour sequences while preserving existing installations.

- Changes the default Cool / Neutral / Warm toggle sequences from 1× / 3× / 5× to 1× / 2× / 3×.
- Automatically migrates existing config entries that contain the former built-in 1× / 3× / 5× values when the integration is upgraded; no visit to Configure is required.
- Preserves other saved click combinations and does not alter learned RF commands, replay modes, fan controls, or transmitter behavior.
